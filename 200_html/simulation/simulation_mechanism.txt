스마트 휠 단차 주행 알고리즘

- 접촉각 θ = 외부휠 중심점, 외부 접촉점, 중간휠 중심점이 이루는 각

① 접촉점 = 0개, 1개
   → 외부휠 정상 구동

② 접촉점 = 2개
   → 접촉각 θ 계산

③ θ = 0°
   → 외부휠 정상 구동
   → 중간휠 0° 복귀

④ θ ≠ 0°
   → 외부휠 구동 잠금
   → 실제 전진거리 Δx 측정
   → 중간휠 Δθ = Δx / R궤도 만큼 회전
   → 내부휠은 기어비에 따라 연동
   → 외부휠 중심 상승

⑤ 위치 갱신 후 θ 재계산
   → θ ≠ 0° : ④ 반복
   → θ = 0° : 외부휠 구동 재개

⑥ 중간휠 |θ| ≥ 약 30°
   → 부족한 높이만큼 차체 보조 상승
   → 실제 위치 기준으로 계속 제어
