- 시뮬레이션 배속은 시뮬레이션의 시간의 흐름의 빠르기만을 결정합니다.

- UI 속도와 휠의 반경에 맞춰서 횔의 회전 속도가 결정되어야 합니다.

- 휠의 회전에 따라서 차량의 위치가 변경됩니다.

- 좌회전/우회전은 사실은 좌중심회전/우중심회전입니다.
  - 회전시에는 차량의 바퀴가 반대로 회전하여야 합니다.
  - 차체가 회전하지만, 회전의 중심점은 4개 휠의 중심점입니다.
  - 회전시에는 4개 휠의 중심점의 좌표가 변하지 않습니다.

- 장애물과 충돌시에 모든 바퀴가 공중으로 부양하면 안 됩니다.
  - 장애물과 접촉하는 바퀴의 고도 값만 증가하는 것이 합리적입니다.

- 휠의 원주 길이 간격으로 그라운드의 그리드를 출력

- 휠의 회전한 원호 길이와 차체 이동 거리가 가급적 동일하여야 합니다.

- 스페이스 키를 입력은 시뮬레이션 일시 정지하거나 재개합니다.

- 회전한 다음에 전진하면 회전한 방향으로 전진하여야 합니다.

- obstacle_pothole은 그라운드를 아래에서 pothole 높이 만큼 음각으로 조합되어야 합니다.

- urdf 모델에서 obstacle_pothole 부피 만큼만 그라운드 상단에 접하도록 음각으로 조합되어 야합니다.

- 속도/배속 슬라이더 상단의 틱을 클릭하여도 값이 변경되어야 합니다.

- 시뮬레이션 정지 상태에서 차량 제어(전진/후진/좌회전/우회전) 버튼을 클릭하면 해당 기능으로 시뮬레애션을 재개합니다.

- urdf model의 ellipsoid_surface와 ground를 무한 확장

- 무한 확장된 ground에도 obstacle_pothole을 동적으로 음각할 예정입니다.

- 0.1 m/s 속도에서만 음각 obstacle_pothole을 통과하지 못합니다.

- 장애물을 등정하는 순간에 휠의 그림자를 장애물 표면에도 출력합니다.
  지표면에 휠이 접촉하지 않으면, 휠의 색상은 회색 계통입니다.

- 시뮬레이션으로 차량이 이동한 위치 만큼, 카메라의 위치도 이동합니다. 
  이 때의, 카메라 위치는 로컬에 저장하지 않습니다.
  시뮬레이션으로 차량이 회전하면, 카메라는 회전하지 않습니다.
